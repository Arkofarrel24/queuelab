    How to read this table

    Analytic is the exact value from the formulas, valid once the system has been running for a very long time. Simulation is an estimate from a number of replications; the ± sign gives the 95% confidence interval, the plausible range for the true value.

    If the formula value falls inside the interval, the two agree. If it falls outside, the most common causes are:

    • ρ ≥ 1: there is no steady state, so the formulas simply do not apply.
    • ρ close to 1: the system needs a very long time to reach steady state. Lengthen the run and the warm-up.
    • Warm-up too short: the empty start gets counted and drags the averages down.
    • Chance: a 95% interval misses about 1 time in 20. Try another seed.
